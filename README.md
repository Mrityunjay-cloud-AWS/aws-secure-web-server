\# Secure AWS Web Server



\## Project Overview



This project demonstrates how to deploy a Linux web server on Amazon EC2 and securely access a private Amazon S3 object using an IAM role.



\## Project Objectives



\* Deploy a Linux web server on EC2.

\* Host a website using Apache.

\* Configure secure SSH access.

\* Automate server setup using EC2 User Data.

\* Store application configuration in a private S3 bucket.

\* Grant EC2 least-privilege access to S3 using an IAM role.

\* Track project changes using Git and GitHub.



\## AWS Services



\* Amazon EC2

\* Amazon S3

\* AWS Identity and Access Management (IAM)

\* Amazon EBS

\* EC2 Security Groups



\## Tools and Technologies



\* Linux

\* Git

\* GitHub

\* Bash

\* HTML and CSS

\* AWS CLI



\## Security Goals



\* Restrict SSH access to an authorized IP address.

\* Keep the S3 bucket private.

\* Apply the principle of least privilege.

\* Use an IAM role instead of permanent AWS access keys on EC2.

\* Enable encryption for stored data.
